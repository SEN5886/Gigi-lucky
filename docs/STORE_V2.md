# 商店 V2 预览

正式路由没有改。`/store`、`/store/[slug]`、`/cart`、`/checkout`、`/admin` 仍是现在线上使用的页面。新界面在 `/store-v2`、`/store-v2/[slug]` 和 `/store-v2/account`。

加入购物车、结算、兑换、库存和订单接口没有换。详情页的「加入购物车」仍调用现有 `/api/mall/cart`，然后进入现有 `/cart` 和 `/checkout`。

## 和参考站的差距

对照 `wstormai.store` 的商店信息架构，而不是它的文案、商标或素材。

| 能力 | 现在 | V2 预览 |
| --- | --- | --- |
| 顶栏 | 浅色胶囊导航 | 仅预览页使用深色顶栏：首页、AI商城、兑换中心、订单查询、教程帮助、账户、购物车 |
| 公告 | 后台 `banner` | 预览页顶栏下展示同一条后台公告 |
| 搜索 | 无 | 预览页按商品名称和简介过滤真实目录 |
| 分类 | 正式商店是横排胶囊 | 预览页电脑左侧、手机横向 |
| 商品卡 / 详情 | 正式商店保持原样 | 预览页使用后台保存的图片；没有图片时用色块封面。详情可真实加购 |
| 客服 | 正式站右下角浮窗 | 预览页同样有「客服」按钮。面板使用后台里的邮箱、服务时间、微信、QQ 和链接，邮箱可直接发信 |
| 消费记录 | `/account/orders` | 预览账户在 `/store-v2/account`。`AUTH_MODE=mock` 时用本地验证码登录，成功后看到该账户的订单和已打码兑换记录 |
| 页脚 | 版权、隐私、售后 | 预览页再加上后台里的客服邮箱和时间。没有公司主体和备案号，所以不编造 |
| 教程 | `/faq` 静态问答 | 导航指向这篇问答，没有另做教程后台 |
| 后台 | `/admin` 口令、商品、文案、客服配置 | 同一地址是客服后台：深色左侧导航，打开总览、用户、商品、订单、页面内容和客服配置。图片可上传、填地址、删除、排序。支付、退款、卡密库存等没有接口的入口停用并标「待接入」 |

## 后台还没有的模块

这些没有真实接口。后台侧栏里对应项是停用状态，标着「待接入」，不能点开。

- SKU / 规格
- 卡密库存和自动发货
- 退款
- 工单
- 操作日志
- 发票
- 教程内容管理
- 独立于顶栏公告的多条公告
- 优惠券
- 真实支付，以及阿里云短信 / 腾讯云邮件的实际发送

用户、商城订单和已打码的兑换记录可以在后台查看。客服备注写在现有的本地账户档案里。完整卡密不出现在后台。

## 回滚

这一版是加页面，不是替换。

1. 不要把线上入口从 `/store` 改到 `/store-v2`。
2. 若要撤回：还原引入 `app/store-v2/`、`components/SiteChrome.tsx`、`components/store-v2/` 和 `docs/STORE_V2.md` 的提交，并把 `app/layout.tsx` 放回原来的页头页脚。
3. 商品、订单、会话和 `.data` 档案不依赖预览路由，撤回页面不会删订单。
